**Alps SKCL Heavy Grey** is a special-purpose heavy linear switch in the "complicated" [Alps SKCL/SKCM series](https://deskthority.net/wiki/Alps_SKCL/SKCM_series "Alps SKCL/SKCM series").[[1]](https://deskthority.net#cite_note-DT-NEC-1)

## Description

It is not clear whether SKCL Heavy Grey is a catalogue switch or a custom production run for a specific NEC keyboard or set of NEC keyboards; the only known keyboard to date was made in 1992. It has been measured using coin stacking as 120 g, twice the weight of the yellow linear switches in the same keyboard, which came out as 60 g. The LED recess is present as with other SKCL switches.

## Keyboards

- NEC PC-9801-98-S02 [M-system](https://deskthority.net/wiki/M-system "M-system") keyboard (1992), used for Stop key at the top-left[[1]](https://deskthority.net#cite_note-DT-NEC-1)
